Windows 电脑 + iPhone：一步一步安装课表小组件
适用版本：iPhone 小组件 1.1.1

这是纯文字教程，不需要“帮助别人制作工具包”、Python、命令行或 Mac。
适用于内蒙古师范大学教务助手。其他学校不能直接照搬学校数据接口与上课时间。
准备：Windows 电脑、iPhone、本人学校账号、手机正在使用的 Apple 账户。
所有登录由本人完成，不需要把密码或验证码交给制作人。
凡是让你“运行脚本”：如果还停在旧课表或预览，先点左上角 Close，
返回 Scripts 列表，再点击正确脚本卡片，才会重新读取文件。

────────────────────
一、Windows 安装教务助手并同步
────────────────────
1. 在电脑浏览器打开：
https://github.com/liuli-cc/imnu-schedule-float/releases/tag/v1.1.1
2. 向下找到“Assets”（资源）。
3. 普通 Intel/AMD 电脑下载名称含 Windows-x64 且以 Setup.exe 结尾的安装包。
   骁龙/ARM 电脑选 Windows-arm64 的 Setup.exe。
   不知道架构：Windows 设置→系统→系统信息→系统类型。
4. 打开安装包，按界面提示安装“教务悬浮助手”。
5. 打开助手，点“授权登录”，在内师大教务官网完成本人登录。
6. 等待同步，确认助手能显示真实课表和正确教学周。

之后更新课表时，先让 Windows 助手完成同步，再传文件。
学校会话过期时需重新登录；手机小组件不保存学校密码。

────────────────────
二、找到电脑已经保存的课表文件
────────────────────
1. 同时按键盘 Win + R。
2. 输入 %APPDATA%，点“确定”。
3. 找到文件夹 imnu-schedule-float-win；如果没有，再找“教务悬浮助手”。
4. 进入后找到 schedule-cache.json。
5. 不要修改文件内容；先记住这个位置。
   如果完全没有这个文件，返回教务助手，完成一次真实课表同步再来找。

这个版本的手机脚本可以直接读此文件，不需要用工具转格式。

────────────────────
三、下载手机脚本
────────────────────
1. 电脑浏览器打开：
https://github.com/liuli-cc/imnu-schedule-float/releases/tag/iphone-widget-v1.1.1
2. 在 Assets 中下载 IMNU-iPhone-Widget-1.1.1.zip。
   这是手机脚本安装文件，不是制作工具包。
3. Windows 中右键这个 ZIP→“全部解压”。
4. 打开解压后的文件夹，找到“内师大课表.scriptable”。
   如果文件后缀没显示，以“内师大课表”且类型为 SCRIPTABLE 文件的那项为准。

────────────────────
四、Windows 把文件传给 iPhone
────────────────────
Windows 没有系统原生隔空投送。这里统一用自己的 iCloud Drive。

电脑操作：
1. 浏览器打开：https://www.icloud.com/iclouddrive/
2. 登录与 iPhone 相同的 Apple 账户，验证由本人完成。
3. 新建文件夹“课表安装”，进入它。
4. 点工具栏的“上传”按钮（向上的箭头）。
5. 上传刚解压得到的“内师大课表.scriptable”。
6. 再点上传，选择第二节找到的 schedule-cache.json。
7. 等两个文件上传完成。

手机操作：
1. App Store 搜索 Scriptable，安装并打开一次。
   官方下载：https://apps.apple.com/app/scriptable/id1405459188
2. 打开“文件”App→“浏览”→“iCloud Drive”→“课表安装”。
3. 等两个文件完成下载。
4. 长按“内师大课表.scriptable”→“共享”→Scriptable。
5. 点“Add to My Scripts”（添加到我的脚本）。
6. 在 Scriptable 列表里点击新增的“内师大课表”运行。
7. 第一次会要求导入课表，点确认，在文件选择器中选择：
   浏览→iCloud Drive→课表安装→schedule-cache.json。
8. 应该看到今天、明天、本周、学期、成绩等页面。

如果共享菜单没有 Scriptable：
把解压包里的“内师大课表.js”也上传到“课表安装”。
手机“文件”里长按这份 .js→移动→iCloud Drive→Scriptable。
再打开 Scriptable，等待脚本出现。不要把文件弄成 .js.txt。

────────────────────
五、把课表放在 iPhone 主屏幕
────────────────────
1. 回到手机主屏幕。
2. 长按空白处，等图标开始抖动。
3. 点“编辑”→“添加小组件”；有些系统是左上角的加号。
4. 搜索 Scriptable。
5. 左右滑动尺寸预览，选“中号”横向组件，点“添加小组件”。
6. 长按刚添加的组件→“编辑小组件”。
7. Script 选择“内师大课表”；如果重复导入有数字后缀，选最新那一份。
8. When Interacting 选 Run Script。
9. Parameter 留空，显示当前/最近一节课；想固定看明天可填 tomorrow。
10. 点外部完成。点击组件，应直接打开完整课表。

大字显示当前或最近一节；小字显示它后面的下一节：开始时间、课程名、教室。
不需要在手机再次登录学校官网。

────────────────────
六、换成自己的头像背景
────────────────────
先准备一张 PNG 横幅：约 2.15:1，推荐 1536×714，4 MB 以下。
人物放右边，左边约 60% 留浅色柔焦区域；文字使用深色。
不要直接用方形头像，不要用左侧有黑色头发或复杂物体的图片。

头像扩图提示词（上传自己的头像后，把这段发给生图工具）：
“把头像扩展成约 2.15:1 的横向课表背景。保留原人物、脸部、发型和画风。
人物放最右侧约 35%–40%。左侧延展同一主题，留浅色、低对比的柔焦区供文字
显示；只虚化左侧，右侧人物清晰。不要绿色、文字、手机外壳或小组件边框。
输出 PNG。”

电脑操作：
1. 保存生成的 PNG，命名为 background.png。
2. Windows 资源管理器可在“查看→显示→文件扩展名”打开后缀显示，
   避免命名成 background.png.png。
3. 如果原文件是 JPG，用 Windows“画图”打开→文件→另存为→PNG 图片。
   只改后缀不算格式转换，画图也不会自动帮你扩图或虚化。
4. 在 iCloud Drive 网页的“课表安装”文件夹里上传 background.png。

手机操作：
1. “文件”→浏览→iCloud Drive→Scriptable。
2. 点右上角“…”→“新建文件夹”，名字输入 IMNU-widget。
   已有这个文件夹就直接使用，不要再建一个同名加数字的副本。
3. 返回 iCloud Drive→课表安装，长按 background.png→复制。
4. 进入 iCloud Drive→Scriptable→IMNU-widget。
5. 长按空白处→粘贴；以后换图遇到同名提示，选“替换”。
6. 打开 Scriptable，运行绑定的“内师大课表”。
7. 在完整课表底部点“预览小组件”→“中号 · 课表概览”。
8. 预览正确后回主屏幕，等待系统刷新。

以后换图重复上传并替换 background.png 即可，不要重装脚本。
想保留图片原色，主屏幕不要使用统一着色外观。
横幅只用于中号组件；小号、大号、锁屏采用原来的普通布局。

────────────────────
七、以后更新课表怎么做
────────────────────
电脑：
1. Windows 教务助手先同步最新课表。
2. 再到 %APPDATA% 中找到同一份 schedule-cache.json。
3. 上传到 iCloud Drive→课表安装，替换旧文件。

手机：
1. 点击主屏幕课表，打开完整课表。
2. 滑到页面底部，点“导入电脑更新的课表”。
3. 浏览→iCloud Drive→课表安装→schedule-cache.json。
4. 看到“课表已更新”后点“好”。

正常跨周不用天天上传。调课、换学期、成绩更新时才需要重新同步。
不会要求重新生成安装包，不会改变你已经选好的头像。

────────────────────
八、自动刷新能做到什么
────────────────────
脚本运行时会按当前时间计算课程，下课后将主课程和“下节”一起向后推进。
它会在上下课边界申请更新，并在上下课前后 15 分钟内约每 5 分钟申请一次。
但 iOS 可以推迟刷新，不能保证下课的那一秒主屏幕就切换。
打开完整课表可以立即按当前时间查看；主屏幕什么时候更新仍受系统安排。
不要将“申请 5 分钟刷新”理解成“保证 5 分钟必定刷新”。

────────────────────
九、最常见的几个问题
────────────────────
运行没东西：确认运行的是新课表脚本，不是 Untitled Script；版本至少 1.1.1。
旧课程：明确导入刚上传的 schedule-cache.json；先确认电脑同步成功。
旧背景：确认在 iCloud Drive/Scriptable/IMNU-widget/background.png，
运行一次脚本并看中号预览；不要放在“我的 iPhone”里的同名文件夹。
组件用错脚本：长按组件→编辑小组件→Script→选择最新正确脚本。
没有 iCloud Drive：在 iPhone 设置→你的姓名→iCloud 中启用 iCloud Drive。
没有 Scriptable 文件夹：先打开 Scriptable，并确认其 iCloud 权限可用。

整个过程不要公开发送自己的课表与成绩，也不要把密码交给其他人。

官方参考：
Scriptable 刷新机制：https://docs.scriptable.app/listwidget/#refreshafterdate
iCloud 上传文件：https://support.apple.com/en-ca/guide/icloud/mmad632d1df2/icloud
