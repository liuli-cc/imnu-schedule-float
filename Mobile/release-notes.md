通过免费 Scriptable App 导入的 iPhone 主屏幕、锁屏课表小组件。小、中、大号显示当前或下一节课、上课时间、教室和当天课程；点击直接打开离线课表，支持今天、明天、本周、学期搜索和成绩。

下载 ZIP 后先阅读“安装说明.txt”。此公开包没有任何用户的课表、成绩、账号或登录状态。请在自己的电脑导出手机 JSON，通过 AirDrop 传给自己的手机，再在 Scriptable 脚本里导入。

手机保持灰紫配色，支持深浅色。教学周依据官网锚点，单双周正常筛选；学校未知周次或假期不猜测。导出不携带姓名、学号、密码、Cookie 和钥匙串凭据。

这是 Scriptable 小组件脚本，**不是独立签名 IPA / TestFlight 安装包**。需先安装 [Scriptable](https://apps.apple.com/app/scriptable/id1405459188)。iOS 决定小组件的真实刷新时机，不能跨其他 App 悬浮。

验证：23 项合成逻辑、隐私导出和 Scriptable API 模拟检查；完整手机课表在 320、375、393、430px 浏览器尺寸与深浅色下检查。目标 iPhone 安装、小组件显示、导入和 AirDrop 接收尚需实机确认。Mac / Windows 最新安装包仍在 v1.1.1。
