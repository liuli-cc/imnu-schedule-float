中号课表小组件新增头像横幅主题：人物在右，文字在左侧柔焦区域，使用奶白、灰蓝和炭黑；完整课表也调整为一致配色。小号、大号保留自适应普通布局，锁屏采用系统外观。

下载选择：

- `IMNU-iPhone-Widget-1.1.0.zip`：无个人数据的 Scriptable 模板。需要导入自己的课表。
- `IMNU-Widget-Creator-Windows-iPhone-1.1.0.zip`：给 Windows 用户的完整制作工具和图文排版教程，包含头像扩图提示词、缓存导出、iCloud 传输、iPhone 安装、数据更新与常见问题。先解压并打开 `Windows+iPhone完整流程.html`。
- Windows 桌面助手安装包仍在桌面版 v1.1.1 发布页，按 x64 / ARM64 选择。本次不更改桌面程序。

制作工具需要 Python 3.10+（含 tkinter），无需第三方 Python 依赖。可选择自己的 PNG/JPEG 横幅，图片直接嵌入脚本。公开包不包含私人头像、课程、成绩或登录凭据。

此版本保留 1.0.1 的课表页面打开修复。重复导入可能产生数字后缀，请在组件设置中选最新脚本；替换 iCloud 中现用同名脚本可保持绑定。
