# 头像课表小组件：Windows → iPhone 完整流程

版本 1.1.0 · 2026-09-27。适用于内蒙古师范大学教务助手已有的课程数据。其他学校需要先适配课程数据与上课时间，不能只换学校名称。全程不需要 Mac、Xcode、付费开发者证书，也不需要把学校密码交给制作工具。

## 1. 准备三样东西

- Windows 电脑：从[教务助手桌面版](https://github.com/liuli-cc/imnu-schedule-float/releases/tag/v1.1.1)下载对应安装包。Intel/AMD 选 x64；骁龙/ARM 电脑选 ARM64。安装包以 Setup.exe 结尾；免安装 ZIP 需要完整解压后运行 IMNUScheduleFloat.exe。
- iPhone：从 [App Store 安装 Scriptable](https://apps.apple.com/app/scriptable/id1405459188)，打开一次；在设置中确认自己的 iCloud Drive 可用。
- 制作工具：完整解压本包，保留所有文件。从 [Python 官网](https://www.python.org/downloads/windows/)安装 Python 3.10 或更新版本，包含 tkinter。不要选择 embeddable ZIP。工具只使用 Python 标准库，不需要 pip、Node 或付费服务。

## 2. 同步自己的课程

打开 Windows 教务助手，在学校官网完成本人登录，然后等待助手显示真实课表。检查本周、下一节课与官网一致；有成绩需要同步时，再确认成绩已缓存。学校会话过期仍需重新授权，手机组件本身不保存或续期学校登录。

双击本工具的 `Create-Widget-Windows.cmd`，它会尝试定位课表缓存。找不到时，按 Win+R 输入 `%APPDATA%`，依次查找 `imnu-schedule-float-win` 或 `教务悬浮助手` 文件夹中的 `schedule-cache.json`，用“选择…”按钮选中。实际目录以本机文件为准。不要选择 settings.json 或浏览器 Cookies 文件。

## 3. 把头像生成横幅

向支持参考图编辑的生图工具上传你自己的头像，使用以下提示词。单纯拉伸方形头像会变形；要进行扩图。输出推荐 1536×714 左右，PNG/JPEG、4 MB 以下，避免使用超大尺寸图片。

> 将这张头像扩展成约 2.15:1 的横向 iPhone 课表小组件背景。保留原头像的人物身份、脸部、眼睛、发型和画风，人物放在画面最右侧约 35%–40%，朝向左边，眼睛和脸完整可辨。向左延展同一主题，不添加其他人物。左侧约 60% 使用奶白底、少量灰蓝光影和非常低对比度的环境细节；文字预计覆盖左侧，因此这片区域必须明显柔焦、虚化，人物保持清晰，过渡自然没有硬边。不要绿色，不要紫色底，不要文字、图标、手机外壳或小组件边框。只输出可直接使用的满幅横向背景。

保存为 `background.png`，在工具“头像横幅”中选择它。留空会使用奶白/灰蓝的普通主题。横幅主题用于**中号**组件；小号、大号采用自适应奶白/深蓝灰布局，锁屏使用系统配色。

先检查：人物眼睛在右侧安全区；左半部没有黑发、强烈线条或复杂物体。工具内置图片，不会自动对任意输入图片做虚化。如果文字仍被干扰，把该横幅交回生图工具，要求“只虚化左侧文字覆盖区并提亮，保持右侧人物不变”，然后重新制作。不要把课程文字一起画进图片。

## 4. 生成自己的安装文件

在制作工具中点“选择保存位置并生成”。会新建日期命名的目录与 ZIP，不会覆盖旧包。

|文件|用途|
|---|---|
|内师大课表.scriptable|首次安装；已经内置自己的课程和背景|
|内师大课表.js|备用导入方式；与安装文件中的脚本相同|
|内师大课表.json|之后更新课程和成绩|
|手机离线课表.html|没有 Scriptable 时的备用完整课表|
|安装说明.txt|手机安装步骤|
|SHA256SUMS.txt|完整性校验清单|

专用包含课程、教师、教室和成绩，但导出器会过滤姓名、学号、学校密码和 Cookie。专用包只传给本人设备；给朋友的是本制作工具包，让对方选择自己的缓存。不要把自己的专用包上传到公共 GitHub。

## 5. Windows 传到 iPhone

推荐使用**本人账户的 iCloud Drive**。Windows 没有系统原生 AirDrop，不需要为了传这个文件购买所谓 AirDrop 软件。

1. Windows 浏览器打开 [iCloud Drive 网页](https://www.icloud.com/iclouddrive/)，登录与 iPhone 相同的 Apple 账户。
2. 新建“课表安装”文件夹，点上传，上传刚生成的 `内师大课表.scriptable`。
3. iPhone 打开“文件”→“浏览”→“iCloud Drive”→“课表安装”，等待文件下载完成。
4. 长按这个文件→“共享”→Scriptable→Add to My Scripts（添加到我的脚本）。
5. 在 Scriptable 点新脚本运行一次，应看到完整课表。无需另外输入学校密码。

如果共享菜单没有 Scriptable：把电脑生成的 `.js` 上传到 iCloud Drive 的 `Scriptable` 文件夹；手机打开 Scriptable 后等待同步。确认是 `.js`，不要变成 `.js.txt`。已有同名文件时先备份，再明确选择替换；替换正在使用的脚本可保持原小组件绑定。

也可以用 iCloud for Windows 在资源管理器里复制文件，详见 [Apple iCloud 设置说明](https://support.apple.com/en-gb/118443)。网页版上传流程见 [Apple 上传与下载指南](https://support.apple.com/en-ca/guide/icloud/mmad632d1df2/icloud)。请在接收者自己的账户操作；不要让制作人获取对方 Apple 密码或验证码。

## 6. 添加主屏幕小组件

1. 长按 iPhone 主屏幕空白处，直到图标抖动。
2. 点“编辑”→“添加小组件”（某些系统显示左上角加号），搜索 Scriptable。
3. 向右切换到**中号横向**组件，点“添加小组件”。
4. 长按新增组件→“编辑小组件”。Script 选择刚导入的课表脚本，When Interacting 选 Run Script。
5. Parameter 留空：显示正在上的课或下一节；填 `tomorrow`：固定显示明天。
6. 点外部完成。点组件，应直接打开课表；可切换今天、明天、本周、学期、成绩。

重复导入时，Scriptable 可能在名称后加 1、2 等数字。必须绑定最新脚本，不能只运行新版而仍让组件绑定旧版。若 iOS 主屏幕开启了“着色”外观，图片可能被系统改色；想保留原头像颜色，请用主屏幕“自定”中的正常浅色/深色外观。锁屏组件不展示这张横幅。

## 7. 日常更新

课程的正常跨周由脚本按教学周锚点计算，无需天天导出。调课、换学期、成绩更新后：电脑同步→重新生成→通过 iCloud 传新的 JSON→在手机课表底部点“导入电脑更新的课表”。只是更新课程时不需要重装小组件。

也可把新的 JSON 命名为 `schedule.json`，放到本人 `iCloud Drive/Scriptable/IMNU-widget/` 目录。脚本运行时会在有效的嵌入数据、手机缓存与该 iCloud 文件中选择最新一份；这不是学校接口的手机后台自动同步。

换头像需要重新生成脚本。推荐备份后替换 iCloud Scriptable 中现用的同名 `.js`；再在手机运行一次。iOS 自行安排主屏幕刷新，运行后没有立即变化时，先查看“预览小组件”，确认新主题已加载，再等待系统刷新，必要时重新选择 Script。组件不能跨其他 App 悬浮，也不能保证秒级刷新。

## 8. 常见问题

|现象|处理|
|运行后没内容|检查是否新脚本；在编辑器点三角运行，查看报错。不要运行空白 Untitled Script。1.0.0 曾有打包问题，使用 1.1.0。|
|组件提示导入|公开通用脚本没有你的数据；使用个人生成包，或导入自己的 JSON。|
|旧颜色或没头像|确认选了中号，脚本来自带图片的包，组件绑定新脚本；排除 iOS 着色外观与缓存。|
|字压住人物|重新生成左侧 60% 留白柔焦的横幅；不要直接用方形头像充当横幅。|
|课程/周次不对|先校对电脑官网的当前周；重新同步并导出，不要手动乱改 JSON 周次。|
|Windows 提示找不到 Python|安装官网 Python 3.10+，重新打开工具；命令行可运行 `py -3 --version` 检查。|
|找不到缓存|先在 Windows 助手完成真实同步；在 `%APPDATA%` 中查找 `schedule-cache.json`。|
|只显示脚本代码|用“共享→Scriptable”导入，或将 `.js` 放进 Scriptable 的 iCloud 文件夹。|
|新文件已传但仍是旧版|关掉旧预览，在“文件”里按修改日期选择新文件；同名副本不会自动替换。|

## 9. 给制作人的复现与验收清单

每个人都使用自己的头像、自己的 Windows 缓存、自己的 iCloud。给对方整包传送本工具即可；无需远程索取学校密码。

验收顺序：先比较手机和官网教学周→比较下一节时间/课程/教室→检查中号预览中人像与文字不重叠→检查长课程名→回主屏幕确认→点击能进完整课表→断网仍能查看。再根据需要测试深色、明天参数与成绩。

命令行替代图形工具（在本工具目录运行）：

```powershell
py -3 export-mobile.py --cache "C:\你的目录\schedule-cache.json" --background "C:\你的目录\background.png" --output "C:\你的目录\我的手机课表"
```

制作无个人数据的公开模板：

```powershell
py -3 export-mobile.py --generic --output "C:\你的目录\公开模板"
```

当前实现的头像横幅由 OpenAI 内置 imagegen 根据参考头像生成；本工具包不包含原作者的私人头像或课程。上面的提示词可让每位使用者生成自己的主题。小组件 API 与刷新限制参考 [Scriptable ListWidget](https://docs.scriptable.app/listwidget/)。Python 安装方式参考 [Python Windows 官方文档](https://docs.python.org/3/using/windows.html)。

测试说明：代码逻辑、导出与 API 模拟不等同于 Windows 图形窗口或 iOS 后台刷新实测；新版本的实际验收状态以随包“验收记录”与发布说明为准。
