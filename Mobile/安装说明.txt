内师大课表 · iPhone 小组件 1.1.0

这个版本使用免费的 Scriptable App 承载 iPhone 主屏幕和锁屏小组件。
它不是可直接安装的 IPA，也不需要购买开发者证书。

从旧版本更新
重新导入新版“内师大课表.scriptable”。Scriptable 会给同名脚本追加数字。
运行最新导入的脚本，并在“编辑小组件”中重新选择它。
1.1.0 支持中号头像横幅，默认改为奶白/灰蓝；保留先前的课表打开修复。

首次安装（只需要做一次）
1. 在 iPhone 的 App Store 安装 Scriptable：
   https://apps.apple.com/app/scriptable/id1405459188
2. 接收隔空投送的“内师大课表.scriptable”。选择用 Scriptable 打开，然后确认添加脚本。
   如果文件留在“文件”App：长按该文件 → 共享 → Scriptable → 添加。
   如果系统没有显示 Scriptable：解压包，把“内师大课表.js”移动到
   “iCloud Drive → Scriptable”目录，然后在 Scriptable 中打开它。
3. 打开 Scriptable 中的“内师大课表”，运行一次。
   你的专用包已带课表；公开包请在提示中选择“内师大课表.json”。
4. 长按 iPhone 主屏幕空白处 → 编辑 → 添加小组件 → Scriptable。
   选择小号、中号或大号。长按小组件 → 编辑小组件 → Script 选“内师大课表”。
   “When Interacting”可选 Run Script；脚本也会自动设置点击打开完整课表。
5. 想显示明天：编辑小组件，在 Parameter 中填 tomorrow；留空默认当前/下一节课。

锁屏也可以添加
长按锁屏 → 自定义 → 锁定屏幕 → 添加小组件 → Scriptable，添加后选这个脚本。
支持行内、圆形和矩形入口，锁屏文字颜色由 iOS 控制。

查看和更新
点击小组件直接打开课表；可以查看今天、明天、本周、全部学期课程和成绩。
不需要重新扫码，不需要将学校密码传给手机。
电脑发生调课或更新成绩后，重新导出手机数据，把新的 JSON 隔空投送到手机。
在手机完整课表底部点“导入电脑更新的课表”选择新的 JSON 即可。
课表按官网教学周自动跨周推进，不需要每天重新导出。
iOS 决定小组件的实际刷新时机，脚本只能申请刷新时间，不能保证实时倒计时。
小组件不能跨其他 App 悬浮；没有承诺读取 iPhone 上其他应用的模型/额度。

隐私
专用包包含你已有的课程、教室、老师和成绩，仅发给你自己的设备。
不包含姓名、学号、学校密码、Cookie、扫码信息或 Mac 钥匙串数据。
请勿把专用包、课表 JSON 或离线 HTML 上传到公共 GitHub。
打开教务官网是独立的 Safari 操作，本版不在手机后台登录学校接口。

限制与验收
本机没有完整 Xcode 和 iOS 签名，未提供独立原生安装版。
逻辑、导出与 Scriptable API 模拟检查不等同于真实 iPhone 安装、显示或 AirDrop 接收成功。
头像横幅在中号显示，左侧柔焦已包含在背景图片中；小号、大号采用奶白/深蓝灰，锁屏颜色由系统控制。
Windows 制作、头像扩图、iCloud 传输完整流程见随附制作工具包。
