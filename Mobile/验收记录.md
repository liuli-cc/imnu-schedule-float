# 1.1.0 验收记录

2026-09-27，在已安装 Scriptable 的目标 iPhone 上通过 iPhone 镜像核验：

- 同名 iCloud 脚本更新后，完整课表已采用奶白与灰蓝配色。
- 中号原生预览正常显示参考头像扩展出的横幅；左侧文字位于柔焦区，人物脸部无文字覆盖。
- 主屏幕现用中号组件已显示新主题，原有脚本绑定保留，点击直接打开新版完整课表。

自动化检查覆盖日历逻辑、课表导出、个人字段过滤、实际打包脚本的 App 执行路径、横幅 Base64 传递、四种宽度的布局参数、公开包与共享工具包完整性；离线 HTML 检查含 5 个视图、搜索、零分及明暗模式。

Windows 导出逻辑与制作包通过自动化验证；Windows 图形窗口的真实鼠标交互、其他 iPhone 尺寸、锁屏主题和 iOS 后台刷新时机未作为实测结果。

公开工具包不包含实际用户的头像、课表、成绩、账户或登录信息。
