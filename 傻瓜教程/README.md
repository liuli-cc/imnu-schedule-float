# 教务助手使用教程

这里单独提供电脑与 iPhone 的逐步安装、同步和换背景说明。打开对应文本文件即可照着点击。

- [Mac 电脑 + iPhone](Mac电脑和iPhone操作教程.txt)
- [Windows 电脑 + iPhone](Windows电脑和iPhone操作教程.txt)

目前教程适用于内蒙古师范大学教务助手及 iPhone Scriptable 小组件。Windows 电脑通过 iCloud Drive 网页传文件；Mac 与 iPhone 可使用 iCloud Drive 或隔空投送。请只将自己的课表文件传到自己的设备，不要上传到 GitHub。
