# 教务悬浮助手 Windows 1.1.1

Intel / AMD 电脑选择 x64；ARM / Snapdragon 电脑选择 ARM64。安装版运行 Setup.exe，免安装版完整解压后运行 IMNUScheduleFloat.exe。免安装版必须保留 resources、DLL 等全部文件，不可只复制 EXE。

第一次打开就会显示悬浮球，并启用登录后自动启动。右键托盘图标可关闭自动启动。免安装版请放在固定位置。

点击“授权登录”，在内蒙古师范大学官网完成首次登录；官方会话有效时可重启复用，不保存明文学校密码。学校让会话过期后仍需重新授权。

点击悬浮球一次即可展开今天、明天、本周、本学期的课表，也能查看全部学期成绩、学分和绩点。点击姓名/学号可打开官网。拖到屏幕边缘可以隐藏，点击边缘入口一次即可打开。点击关闭只收起面板，悬浮球继续保留。

配色为灰紫色，Windows 11 22H2 及以上使用系统 Acrylic，Windows 10 使用半透明面板。断网保留课表和成绩，不会把网络错误当作登出；网络恢复或电脑唤醒后会自动重试。

更新安装保留本机缓存和登录会话。卸载会移除安装版的自动启动项，不自动删除用户数据。可在应用内按住 Shift 点击“•••”，确认后清除本机课表和登录状态。

发布包尚无商业发布者签名，首次下载可能出现 Windows 开发者确认。确认下载来自本仓库后按系统提示打开，不需要关闭系统安全功能。

ARM64 包已经检查实际 EXE 架构，尚未经过 Windows ARM 实机验收。
