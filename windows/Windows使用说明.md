# 教务悬浮助手 Windows 版

## 安装

双击 `教务悬浮助手-Windows-1.0.1-x64-安装包.exe`，选择安装目录并完成安装。支持 Windows 10/11 x64，不需要另行安装 Python、Node.js 或浏览器驱动。

由于当前安装包没有商业代码签名证书，Windows SmartScreen 可能显示“未知发布者”。确认文件来自本项目后，可选择“更多信息”→“仍要运行”。

## 首次使用

1. 启动后会打开内蒙古师范大学官方统一身份认证页面。
2. 按官网提示完成微信扫码或账号授权。
3. 登录成功后，程序会直接读取当前账号的本学期课表、姓名、学号和绩点，并关闭授权窗口。
4. 后续启动会恢复当前 Windows 用户的登录会话；程序启动、每 45 分钟及电脑唤醒后会尝试自动同步。只有学校使会话失效或要求二次验证时才需要重新登录。

## 操作

- 单击悬浮球：展开或收起课表。
- 拖动悬浮球：移动位置。
- 拖到屏幕左右边缘：自动收成竖条；鼠标指向或单击竖条后恢复。
- “今天 / 本周 / 本学期”：切换课表范围；“本学期”可选择具体教学周。
- 每节课的“第几节”下面会显示上课时间；时间与教务系统课表一致。
- 托盘图标：可显示课表、立即同步、重新登录或退出程序。

账号会话和课表缓存只保存在当前 Windows 用户的应用数据目录，不会打包进安装程序，也不会共享给其他用户。
